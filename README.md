# Android Screen Share

一个面向 Windows 10/11 的 Android 投屏小工具。它把 [scrcpy](https://github.com/Genymobile/scrcpy) 的常用参数整理成中文图形界面，并附带一个极小的开源 Android 通知助手，让你可以直接从手机通知栏停止对应的投屏。

项目源码不包含任何固定的设备序列号、手机型号或局域网地址。为了恢复上次选择，程序只在用户电脑的 `data/settings.json` 中保存所选设备和界面选项；该目录不会提交到 GitHub，也不会上传到任何服务器。

## 功能

- USB 与无线 ADB 投屏
- 自动识别已连接的 Android 设备与型号
- 普通手机镜像、桌面/虚拟显示器两种模式
- 1080p 或 1440p、30/60 FPS、8/16/24 Mbps
- Android 11+ 无线调试配对，以及“先插 USB 再开启无线”的快捷流程
- 可选声音转发、普通镜像时关闭手机屏幕
- scrcpy 窗口默认出现在鼠标所在的显示器
- 手机常驻通知显示当前分享状态，并可单独停止普通镜像或桌面模式
- 两种投屏可分别运行，停止其中一种不会误关另一种
- 自动记住上次选择的设备、无线地址、模式、画质、帧率、码率、声音和关屏选项
- 在程序内一键检查并安装更新
- 图形界面以无控制台方式启动，不再常驻空白 CMD 窗口

> [!IMPORTANT]
> “桌面/虚拟显示器”不是三星官方 Wireless DeX，也没有破解或伪装三星协议。工具让 scrcpy 在手机里创建一块额外的虚拟屏幕，然后尝试在这块屏幕上打开桌面环境。三星设备通常会显示较完整的桌面界面；其他品牌可能显示普通 Android 界面、简化桌面，或不支持该行为。

## 系统要求

- Windows 10 或 Windows 11
- 一台已开启“开发者选项”和“USB 调试/无线调试”的 Android 设备
- Android 8 及以上（通知助手最低要求）
- 声音转发通常需要 Android 11 及以上
- Android 11 及以上可使用系统自带的无线调试配对
- 首次安装与下载 scrcpy 时需要网络

不需要 Root，不需要云服务，也不需要三星账户。

## 最快上手

1. 在仓库页面点击 **Code → Download ZIP**，下载后完整解压；也可以克隆本仓库。
2. 双击 `Setup.cmd`。安装程序会从 scrcpy 官方 GitHub Release 下载最新版 Windows x64 包，并在桌面创建快捷方式。
3. 在手机中开启开发者选项：通常是“设置 → 关于手机 → 软件信息”，连续点击“版本号”7 次。
4. 回到开发者选项，开启“USB 调试”。使用数据线连接电脑，在手机上允许这台电脑调试。
5. 打开桌面的 **Android Screen Share**，点击“刷新”，选择手机。
6. 选择模式、分辨率、帧率和码率，然后点击“开始投屏”。
7. 首次使用时，工具会询问是否安装通知助手。选择“是”，之后手机通知栏会常驻显示分享状态。

如果你只是想稳定地看视频，建议先用：普通手机镜像、1080p、60 FPS、16M、声音转发。网络稳定后再改为 1440p 或 24M。

### 一键更新

程序右上方提供“检查更新”按钮。发现新版本后确认更新，工具会自动下载本仓库的最新代码，保留已经下载的 `tools/scrcpy` 和本机 `data` 设置，完成校验后重新启动。也可以直接双击安装目录中的 `Update.cmd`。

从没有更新器的旧版本升级时，需要最后一次重新下载完整项目并运行 `Setup.cmd`；此后不再需要手动删除、下载和解压。

## 三种连接方法

### 方法一：USB（最稳定）

1. 开启 USB 调试。
2. 用支持数据传输的 USB 线连接手机。
3. 在手机弹窗中允许调试。
4. 打开工具，点击“刷新”并选择标有 `[USB]` 的设备。

### 方法二：插一次 USB，再转无线

此方式适用于大多数 Android 设备，手机与电脑必须位于同一局域网。

1. 先按 USB 方法连接并选择手机。
2. 点击“通过所选 USB 设备开启无线连接”。
3. 工具会读取手机当前 Wi-Fi 地址、执行 `adb tcpip 5555` 并自动连接。
4. 设备列表出现标有 `[无线]` 的条目后，即可拔掉 USB 线。

这个方法不会在手机上显示新的配对提示；手机此前显示并接受的 USB 调试授权就是本次操作使用的权限。部分手机重启、切换 Wi-Fi 或关闭开发者选项后需要重新执行一次。

### 方法三：Android 11+ 无线调试配对

1. 手机与电脑连接同一 Wi-Fi。
2. 在开发者选项中打开“无线调试”。
3. 点击“使用配对码配对设备”，手机会显示配对 IP、端口和六位配对码。
4. 在工具的“IP:端口”中填入配对地址，在“配对码”中填入六位数字，点击“配对”。
5. 回到手机无线调试主页，查看单独列出的“IP 地址和端口”。该端口通常与配对端口不同。
6. 把“IP:端口”改为连接地址，点击“连接”，然后刷新设备列表。

## 两种投屏模式

### 普通手机镜像

直接显示和控制手机当前屏幕。支持可选的“关闭手机屏幕”，适合视频、应用操作与日常镜像。

### 桌面 / 虚拟显示器

scrcpy 使用 `--new-display` 在手机中创建第二块逻辑屏幕，电脑窗口显示的是这块虚拟屏幕，而不是复制手机面板。工具随后给新屏幕发送一次 Home 键，尝试唤起系统为外接屏准备的桌面或启动器。

- 三星设备通常兼容性最好，可能进入类似 DeX 的桌面体验。
- 其他 Android 设备的效果取决于厂商系统。
- 这不是 Miracast，因此画质、延迟和控制仍由 scrcpy/ADB 链路负责。
- 桌面模式不会自动关闭手机屏幕，手机面板可自行开关。

## 手机通知与“停止分享”

首次启动投屏时，电脑会安装仓库中的开源 `companion.apk`。它只负责显示前台常驻通知和发送停止请求，不采集屏幕、不访问公网，也不保存设备信息。APK 声明网络权限仅用于连接 `127.0.0.1` 上由 ADB 反向映射的本机端口。

- 普通镜像显示“手机屏幕正在分享”。
- 桌面模式显示“桌面屏幕正在分享”。
- 点击通知中的“停止分享”，通知助手会通过 `adb reverse` 连接到电脑端本地监听端口。
- 电脑确认收到请求并关闭对应 scrcpy 进程后，手机端才撤销该通知。
- 两种模式使用不同端口和通知 ID，所以可以分别停止。

Android 会把正在运行的前台服务显示为常驻通知；某些系统仍可能允许用户暂时隐藏通知显示，这是系统权限行为，应用不会主动把运行中的通知划掉。

## 画质与流畅度建议

| 使用场景 | 分辨率 | 帧率 | 码率 | 连接 |
|---|---:|---:|---:|---|
| 稳定优先 | 1080p | 60 | 8M–16M | USB / 5 GHz Wi-Fi |
| 清晰优先 | 1440p | 60 | 16M–24M | USB 或信号良好的 5/6 GHz Wi-Fi |
| 网络一般 | 1080p | 30 | 8M | 无线 |

1440p 不代表手机应用一定输出原生 2K 内容，它只是提高投屏编码尺寸。更高分辨率和码率会增加手机编码功耗、无线流量与电脑解码负载。

## 常见问题

### 显示多个 ADB 设备，无法启动

本工具会把所有设备列出来，并始终给 scrcpy 传入所选设备序列号，因此不会依赖模糊的 `-d` 或 `-e`。请在下拉框中选择正确设备。

### 设备显示 unauthorized

解锁手机并接受 USB 调试授权。若没有弹窗，可在开发者选项中“撤销 USB 调试授权”，重新插线后再授权。

### 无线连接重启后失效

这是 Android/ADB 的正常行为。`adb tcpip 5555` 可能在重启后恢复默认；重新插 USB 开启，或改用 Android 11+ 的无线调试配对。

### 无线经常断开

优先使用 5 GHz 或 6 GHz Wi-Fi，关闭手机的省电模式，确保电脑和手机位于同一路由器网络。仍不稳定时降低到 1080p、8M，或使用 USB。

### 没有声音

确认勾选“转发声音”，并使用 Android 11+。部分应用会禁止音频捕获；受 DRM 保护的视频也可能无声或黑屏。

### 桌面模式不是 DeX 界面

不同品牌、Android 版本和桌面启动器对虚拟显示器的处理不同。该功能只保证请求创建虚拟显示器，不保证厂商一定提供桌面 UI。三星系统更新也可能改变行为。

### 提示 ADB server version 不一致

关闭其他手机助手、模拟器或旧版 ADB，然后重新启动本工具。项目固定使用下载到 `tools/scrcpy` 内的同一套 `adb.exe` 与 `scrcpy.exe`，可减少版本冲突。

### 提示 `Could not execute "adb start-server"`

先重新运行 `Setup.cmd`。安装程序会检查 `adb.exe` 及其 DLL 是否完整，并实际测试内置 ADB。新版工具还会覆盖电脑中错误或过期的 `ADB` 环境变量，确保 scrcpy 使用 `tools/scrcpy/adb.exe`。如果安装检查仍失败，请打开“Windows 安全中心 → 病毒和威胁防护 → 保护历史记录”，确认 `adb.exe` 没有被隔离；本项目只支持 Windows 10/11 x64。

### 防火墙是否需要放行端口

通知停止功能使用 ADB 反向端口映射，只监听电脑的 `127.0.0.1`，不会向局域网开放 27284/27285。无线 ADB 本身仍受手机无线调试和局域网策略影响。

## 隐私与安全

- 项目不包含也不会写死任何设备序列号、型号或 IP。
- 投屏数据由 scrcpy 在电脑与设备之间直接传输，没有中转服务器。
- 通知助手声明网络权限，但只连接由 ADB 映射到 `127.0.0.1` 的本机停止端口，不访问公网。
- 停止服务只连接通过 ADB 映射到电脑本机的回环端口。
- 请只在可信电脑上授予 USB/无线调试权限，用完公共电脑后撤销授权。

安全问题请参阅 [SECURITY.md](SECURITY.md)。

## 从源码运行

```powershell
git clone https://github.com/OrangeYi/android-screen-share.git
cd android-screen-share
.\Setup.cmd
```

`tools/scrcpy` 是安装时下载的本地依赖，已被 `.gitignore` 排除，不会提交到仓库。

### 构建 Android 通知助手

需要 JDK 17、Android SDK 和 Gradle 8.9：

```powershell
cd companion
gradle :app:assembleDebug
```

输出 APK 位于 `companion/app/build/outputs/apk/debug/`。Release 中的 `assets/companion.apk` 是从本目录源码构建的预编译版本，方便普通用户直接安装。

## 项目结构

```text
app/                         Windows 图形界面与投屏控制
assets/companion.apk         预编译 Android 通知助手
companion/                   通知助手完整 Android 源码
locales/zh-CN.json           中文界面文字
Setup.cmd / Setup.ps1        下载官方 scrcpy、创建快捷方式
Start-AndroidScreenShare.cmd 启动图形界面
```
